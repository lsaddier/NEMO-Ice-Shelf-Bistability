### Data and code Supplement for the Manuscript 

**"Bistability of ice-shelf cavity circulation and melt under coastal polynya forcing"**

Submitted to *Journal of Geophysical Research: Oceans*. Data and code supplement associated to the submitted version (15/10/2026).

This repository contains the data and code associated with the above manuscript. If you use or refer to this code, please cite the accompanying publication.

### Getting Started

To set up the environment and run the code, execute the following commands in a terminal:

```
git clone https://github.com/lsaddier/NEMO-Ice-Shelf-Bistability.git
cd NEMO-Ice-Shelf-Bistability
conda env create -f environment.yml
conda activate NEMO-Ice-Shelf-Bistability
jupyter notebook
```
